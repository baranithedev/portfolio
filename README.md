# 🌐 Barani.Dev Portfolio

A modern, responsive portfolio website built with **React**, **Vite**, **Bootstrap 5**, and **React Router**. It showcases my work, pricing, skills, and contact information with a clean UI and built-in Light/Dark theme support.

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react)
![Vite](https://img.shields.io/badge/Vite-7-646CFF?logo=vite)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5-7952B3?logo=bootstrap)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

- 🌙 Light & Dark Theme
- 📱 Fully Responsive Layout
- ⚡ Powered by Vite
- 🧭 React Router Navigation
- 🏠 Home Page
- 💰 Pricing Plans
- 👨‍💻 About Page
- 📩 Contact Page
- 🚫 Custom 404 Page
- ♻️ Reusable Components

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/baranithedev/portfolio
```

### Go to the project folder

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```

---

## 📜 Available Scripts
